## 第一阶段：内容编辑 + AI 适配 + 模拟发布

目标：输入一篇文章，生成公众号、知乎、小红书、B站四种预览。

交付内容：

- 统一内容 IR
- 平台 Adapter 接口
- 四个平台 profile
- 多 Agent 编排接口
- 模拟发布任务接口
- 前端编辑、预览、任务看板和账号页面
- 共享素材库和正文素材引用

## 第二阶段：真实发布闭环

优先接入能力相对明确的平台，形成真实闭环：

- 公众号草稿、素材上传、人工确认群发
- B站视频稿件发布、查询、删除或 biliup 辅助
- 小红书通过 myaibot API 提交笔记，用户扫码完成最终发布

当前后端实现目标：

- 公众号：上传素材、创建草稿、提交发布、查询发布状态。
- B站：passport 密码登录保存 Cookie 凭据，支持视频/封面上传、稿件提交、状态查询、删除测试稿件。
- 小红书：通过 `publish-with-upload` 提交标题、正文、图片/视频和封面；需要全局 API Key、素材公网 URL 和素材上下文，账号入口与状态轮询仍待完善。
- 真实发布任务通过 Celery + Redis 异步执行。
- 账号凭据加密保存到 PostgreSQL。
- 数据库结构通过 Alembic 迁移管理。

待补齐：

- 小红书账号管理入口、连接测试、二维码/状态轮询和真实联调。
- 发布失败时更细的错误恢复建议。
- 前端对小红书二维码/状态轮询的完整展示。

## 第三阶段：浏览器辅助发布

知乎先做人机协同，小红书可作为 API 发布失败时的备用路线：

- 打开发布页面
- 自动填充标题、正文、图片和标签
- 用户手动处理验证码、风控和最终发布确认

## 第四阶段：Agent 工作流

加入任务规划、格式检查、合规检查、失败恢复和发布报告。

## 第五阶段：数据反馈

抓取阅读、点赞、收藏、投币等数据，反哺下一次标题和平台风格建议。

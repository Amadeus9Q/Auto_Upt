# MVP 路线

## 第一阶段：内容编辑 + AI 适配 + 模拟发布

目标：输入一篇文章，生成公众号、知乎、小红书、B站四种预览。

交付内容：

- 统一内容 IR
- 平台 Adapter 接口
- 四个平台 profile
- 多 Agent 编排接口
- 模拟发布任务接口
- 前端编辑、预览、任务看板和账号页面骨架

## 第二阶段：B站和公众号真实发布

优先接入官方能力相对明确的平台，形成真实闭环：

- 公众号草稿、素材上传、人工确认群发
- B站视频稿件发布、查询、删除或 biliup 辅助

## 第三阶段：浏览器辅助发布

知乎和小红书先做人机协同：

- 打开发布页面
- 自动填充标题、正文、图片和标签
- 用户手动处理验证码、风控和最终发布确认

## 第四阶段：Agent 工作流

加入任务规划、格式检查、合规检查、失败恢复和发布报告。

## 第五阶段：数据反馈

抓取阅读、点赞、收藏、投币等数据，反哺下一次标题和平台风格建议。
